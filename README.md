## <span style="color:#D96C5F;">About</span>

**ordrly** gives small businesses a simple way to manage their **products, orders, inventory, and payments** while continuing to sell through Instagram.

The goal is simple:

> <span style="color:#5B4057;">Make selling through Instagram feel more organized.</span>

---

## <span style="color:#D96C5F;">Tech Stack</span>

| **Layer**   | **Technology**                    |
| :---------- | :-------------------------------- |
| Frontend    | `React` · `Vite` · `Tailwind CSS` |
| Backend     | `FastAPI` · `Python`              |
| Database    | `Supabase` · `PostgreSQL`         |
| Payments    | `Cashfree`                        |
| Integration | `Instagram / Meta APIs`           |
